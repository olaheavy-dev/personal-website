# 0005: Claims policy

**Status:** Accepted  
**Date:** 2026-10-24  
**Decided by:** the owner, in the design-flow grill session

## Context

Most CV figures have no public source, some conflict with public data, and employers' internal work is confidential. A portfolio that overclaims loses trust.

## Options

- Use CV numbers as written
- Public facts only
- Use numbers, precisely worded and sourced

## Decision

Every number on the site carries a source (public link, repository link, or "own measurement"). The per-company table in `.design/portfolio/DESIGN_BRIEF.md` is binding: HBK names only Aiana publicly (later features described generically; no internals); Access QuickBucks shows only 1M+ Google Play downloads; Stanbic EZ Cash shows no number; Optty uses public dated figures; uLesson shows no figures, like Stanbic IBTC (owner decision, 25 Oct 2026, replacing the two figures the table once held); Galooli's ~11% is attributed to Galooli; Mukuru never implies the 2024 Malawi wallet launch; RagLab is not shown as personal work.

## Consequences

- Reviewers treat an unsourced or policy-breaking claim as P1.
- Changes to this policy are owner-merged.
