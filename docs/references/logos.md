# Company logos

Logos of the companies on the route, in `public/logos/`, for the logo rail and `LogoMark` (#9). They are the companies' trademarks, shown to say where the owner has worked, and are never redrawn or restyled. None of the eight companies publishes a brand kit or usage guidelines that we could find, so every file comes from the company's own website or files. Retrieved and checked 25 Oct 2026; the owner approved the list on #9.

The rail shows each logo in one colour from the design tokens and the brand colour on hover (design brief). A logo becomes one colour through a CSS mask, which keeps only its shape. Two logos have white details drawn on top of coloured shapes that a mask would hide, so they also have a `-mono` version where those details are holes (a knockout): the same shapes, nothing redrawn.

## Hover colours (logo rail, #9)

At rest every logo is `--color-text-tertiary`. On hover (pointer devices only) it takes its company's colour, one token per client in `src/styles/tokens.css` and `.design/portfolio/DESIGN_TOKENS.css` (`--color-logo-<slug>`, light and dark). Every value is a fill that appears in that company's own file in `public/logos/` (for the `-mono` ones, the original colour file). Nothing is invented. Each colour must reach 3:1 against the page background (`#faf8f5` light, `#131217` dark), because a hover colour is a graphical object; `src/lib/logos.test.ts` checks it. The company's name is also in text, so the rail never relies on colour.

## Tool logos (Toolkit on /work, #10)

Ten logos of tools the owner works with, in `public/logos/tools/`, for the chip plates in the Toolkit (`src/lib/toolkit.ts`). Each is the tool's official logo in its own colours, shown unmodified on a paper plate (paper in both themes, so black marks stay visible) to say which tools the owner uses. Every other tool shows a real abbreviation (AWS, GCP, GHA, ADO) or our own group icon, because its brand rules forbid showing the logo this way, need permission, or no logo exists. Downloaded and checked on 27 Oct 2026; the owner approved the list on #10.

What "sanitised" means here: the downloads were parsed, never run, and written back as plain copies with no XML prolog, comments, metadata, title, editor attributes, classes, style elements or style attributes (their values became attributes), no width or height, no external reference, and a viewBox cut to the drawn shape. Shapes and colours are untouched except where the table says otherwise. `scripts/check-logos.test.ts` checks the folder, and each file is listed in the matcher in `src/proxy.ts`.

The Toolkit uses the group's own line icon, or a real abbreviation (AWS, GCP, GHA, ADO) with the full name as the chip text.

Why three more are left out (a pre-push review finding, 27 Oct 2026):

- **Microsoft Agent Framework and Playwright.** Microsoft's Trademark and Brand Guidelines say its logos and product icons need an express licence, and an open source software licence (the repositories are MIT) is not a trademark licence. The same reasoning already excludes Azure and Foundry. Playwright is a Microsoft project, so the same guidelines apply.
- **Terraform.** HashiCorp asks third parties to use the attributed logo, the one that includes the HashiCorp name, which cannot be read at 28 px.

Their Toolkit chips use the group's line icon instead.

A logo that is the name itself (a wordmark, today only Redis) stands alone in its chip, with the name as its alt text and no text name beside it (owner's rule, 27 Oct 2026).

Trademark symbols: the PSF's policy asks that its logos carry a trademark symbol, so the Python chip shows ™ after the name (the notice also names the PSF); Redis's policy asks for ®, so the Redis chip shows it.

The notice under the Toolkit (28 Oct 2026) is three required sentences plus one general line. The Vercel, Python and Redis sentences stay word for word because each brand's policy asks for them (see the rows above). The general line was shortened to "Names and logos are trademarks of their owners, shown only to name the tools I use." It still covers the tool names shown without a logo. It no longer says "do not imply endorsement": no policy requires that sentence, and the rules against implying endorsement (TypeScript, Redis) are met by how the marks are used, not by a notice.
